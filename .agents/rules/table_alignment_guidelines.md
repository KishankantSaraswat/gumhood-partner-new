# Table Column Alignment Standards

Follow these column alignment standards strictly across all tables, reports, and data grids (`DataTable`, `GroupedDataTable`, and any custom tables):

| Data Type | Alignment | Examples / Notes |
| :--- | :--- | :--- |
| **Text** | `Left aligned` | Names, descriptions, addresses, branch names, item names, remarks |
| **Numbers / Quantities** | `Right aligned` | Quantities, counts, units, weights |
| **Currency / Amounts** | `Right aligned` | Gross amount, net amount, tax amount, debit, credit, unit rate, totals |
| **Percentages** | `Right aligned` | Tax rates (e.g. 18%), discounts (e.g. 5%), ratios |
| **Dates / Timestamps** | `Left aligned` | Invoice date, PO date, creation date, created_at |
| **IDs / Codes / Ref No** | `Left aligned` | Invoice No, PO Number, SKU, Reference No, Voucher No (unless purely numeric and convention specifies) |
| **Status / Badges / Actions** | `Center aligned` | Status badges (Draft, Approved, Active, Inactive), icons, action buttons |
